    📰 Island Insight
</h1>

<p style="font-family: 'Roboto', sans-serif; text-align: center;">
    Island Insight is a modern news application designed to deliver real-time news articles focused on Sri Lanka, as well as the latest updates in sports and technology. Built using React, Firebase, and Tailwind CSS, the app aims to provide users with a seamless and engaging experience for consuming news.
</p>

## Features
- 📰 **Real-time News Fetching:** The application fetches the latest news articles, ensuring users have access to the most current information.
- 📱 **Responsive Design:** Built with Tailwind CSS, the app features a responsive layout that adapts seamlessly across various devices.
- 🔐 **User Authentication:** Integrates Firebase Authentication for secure user sign-up and sign-in, enabling personalized experiences with options for Google, Apple, and Facebook authentication.
- 👍 **Likes and Comments:** Users can like articles and post comments, with real-time updates managed through Firebase Firestore, fostering an interactive community.
- 🖼️ **Dynamic Article Display:** Articles are presented in a grid format, featuring skeleton loaders during data fetching to enhance user experience.
- 🔍 **News Article Popup:** Clickable cards open a detailed view of the news articles, providing a more immersive reading experience.

## Technologies Used
- ⚛️ **React:** For building user interfaces.
- 🔥 **Firebase:** For backend services including authentication and real-time database functionalities.
- 🎨 **Tailwind CSS:** For styling and responsive design.

## Installation
1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies.
4. Set up environment variables in a `.env` file with the following keys:
    ```
    REACT_APP_FIREBASE_API_KEY=<your-api-key>
    REACT_APP_FIREBASE_AUTH_DOMAIN=<your-auth-domain>
    REACT_APP_FIREBASE_DATABASE_URL=<your-database-url>
    REACT_APP_FIREBASE_PROJECT_ID=<your-project-id>
    REACT_APP_FIREBASE_STORAGE_BUCKET=<your-storage-bucket>
    REACT_APP_FIREBASE_MESSAGING_SENDER_ID=<your-sender-id>
    REACT_APP_FIREBASE_APP_ID=<your-app-id>
    REACT_APP_FIREBASE_MEASUREMENT_ID=<your-measurement-id>
    ```
5. Start the development server.
